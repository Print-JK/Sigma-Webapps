Welcome to WordCraft

This is your distraction-free, local-first word processor running 100% in your browser without any server or cloud dependencies.

Key Capabilities

WordCraft provides an authentic editing experience with real-time formatting, tables, image insertion, and seamless file conversions:

  • Microsoft Word (.docx) Compatibility: Open and read existing Word documents via offline extraction and export full OOXML .docx files.
  • Clean Typography & Layouts: Standard A4 dimensions with margin customization, ivory parchment and dark modes.
  • Tables & Media: Insert responsive data tables and embed local graphics directly into the document structure.
  • Zero-Telemetry Privacy: All keystrokes, content, and files remain strictly inside your browser.

Start typing, paste text, or open an existing file from the top bar to begin!
